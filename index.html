stupid-dom-logger v2

console.log, but on the page.

One script tag turns every console.* call into an on-screen toast. You get an object inspector, readable stack traces with source previews, and uncaught errors, without opening DevTools. Handy on phones, kiosks, embedded webviews, and screen shares.

<script src="https://cdn.jsdelivr.net/gh/immannino/stupid-dom-logger/dist/stupid-dom-logger.min.js"></script>
GitHub

Log levels

Every level gets its own colour. Click the file name on a toast to see the full call stack.

Object inspector

Objects expand lazily, like DevTools. Circular references, Maps, Sets, classes, and DOM nodes are handled. Hover a DOM node to highlight it on the page.

Errors & stack traces

Stacks are parsed for Chrome, Firefox, and Safari. Vendor frames are dimmed, and the line that threw is fetched and shown with a caret.

The rest of the console

Format specifiers, %c styling, tables, counters, and timers all work.

Noise control

Repeated messages collapse into one toast with a ×N counter. Hover the stack to pause timers. Interact with a toast to pin it.

API

Zero config works fine, but everything can be changed.

// Before the script loads…
window.StupidDomLoggerConfig = { position: 'top-right', levels: ['warn', 'error'] };

// …or on the script tag…
<script src="stupid-dom-logger.min.js" data-position="top-left" data-duration="3000"></script>

// …or at runtime.
StupidDomLogger.configure({ theme: 'dark', maxToasts: 3 });
StupidDomLogger.toast('info', 'Shown without touching the console', { ok: true });
StupidDomLogger.clear();
StupidDomLogger.disable();   // .enable()
StupidDomLogger.uninstall(); // restores the original console
StupidDomLogger.history;     // every message seen, newest last
